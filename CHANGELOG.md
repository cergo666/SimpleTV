# Changelog

## SimpleTV 1.3.0

Встроенное автообновление приложения.

- Android: проверка GitHub Releases, загрузка APK, проверка SHA-256 и запуск системного установщика через FileProvider.
- Windows: установка через `Setup.exe` в тихом режиме; портативная версия запускает новый `Portable.exe`.
- Linux: AppImage скачивается, проверяется по SHA-256 и заменяется с перезапуском.
- Проверка обновлений также доступна вручную в настройках; автоматическая — через несколько секунд после запуска.
- В каждый релиз добавляется `SHA256SUMS`, чтобы клиенты могли проверять целостность загрузок.

## SimpleTV 1.2.0

Плановое обновление надёжности, локализации и сборки.

- Единый источник версии (`version.properties`) для Android, desktop, Windows/Linux-пакетов и документации.
- Android lint подключён к `:core`; устранены предупреждения `FrequentlyChangingValue`, `PluralsCandidate` и `UnusedAttribute`.
- Иконки и ресурсы совместимы с Android 6 (API 23), градиенты вынесены в `drawable-v24`.
- Списки каналов и телегид больше не вызывают лишние рекомпозиции при прокрутке.
- Стартовая загрузка плейлистов защищена от исключений, кэш EPG синхронизирован.
- Состояние ввода в диалогах и `resumePlayback` переживают пересоздание Activity.
- Локализованы оставшиеся строки плеера, статистики, DRM-бейджей и установщика Windows.
- Проверка SHA-256 для `libmpv` и `appimagetool`, проверка наличия обязательных инструментов сборки.
- Обновлены совместимые Flutter- и Android-зависимости; зафиксированы версии, требующие `compileSdk 37.1`/`minSdk 24`.
- Минимальный размер окна desktop — `960×600`; кэш логотипов использует SHA-256.

## SimpleTV 1.1.0

Масштабное обновление дизайна, контрастности и навигации с пульта для Android TV, смартфонов, Windows и Linux. Подробности — в [RELEASE_NOTES.md](RELEASE_NOTES.md).

- Безопасная зона ТВ, переработанный `FocusItem`, подсказки пульта и навигация на экранах ошибок.
- Перемотка архива, индикаторы паузы и перемотки, улучшенный телегид.
- Высококонтрастная палитра для всех шести акцентов, ручной выбор режима интерфейса.
- Синхронизированы токены и масштабирование шрифтов в настольной версии.

## SimpleTV 1.0.0

Первый публичный выпуск кроссплатформенного IPTV-плеера для Android, Android TV, Windows и Linux.

- Главный экран с недавними каналами, избранным и текущими передачами.
- Телегид с поиском, временной шкалой, информацией о передаче и просмотром архива у поддерживаемых источников.
- Автообновление встроенных каталогов, объединение каналов и переключение на резервные источники.
- Управление пультом, мышью и клавиатурой. Опциональный предпросмотр по OK на Android TV.
- Русский и английский интерфейс, темы оформления, портативная версия Windows и автономные пакеты Linux.
