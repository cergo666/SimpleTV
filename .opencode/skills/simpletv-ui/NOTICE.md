# Источники

`simpletv-ui` написан для SimpleTV и перерабатывает принципы из открытых скиллов. Тексты в этом каталоге не являются копиями исходных файлов.

- **ui-taste** — Uizze, Apache-2.0. Идеи: anti-slop craft, craft checks, state cycles, motion frequency gate. https://skills.sh/site/uizze.sh/ui-taste
- **mobile-app-ui-design** — ceorkm, MIT. Идеи: 8-pt grid, типографическая шкала, 60/30/10, состояния экранов. https://skills.sh/designed-by-ai/skills/design-mobile-apps
- **Impeccable** — Paul Bakaus, Apache-2.0. Идеи: polish/critique/distill, проверка реального рендера. https://skills.sh/pbakaus/impeccable/polish

Правила Android TV (10-foot, D-pad, overscan) добавлены для этого проекта и не взяты из перечисленных скиллов.
