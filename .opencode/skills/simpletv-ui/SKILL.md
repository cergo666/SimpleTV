# SimpleTV UI

Единый набор правил для двух клиентов: Android/Android TV на Compose и Flutter desktop для Windows/Linux. Цель — предсказуемый, читаемый с 2–3 метров интерфейс плеера без визуального шума.

## Порядок работы

1. Определи платформу и режим: Android TV, Android-телефон (портрет/альбом), Flutter desktop.
2. Открой актуальные токены в `reference/design-tokens.md`, затем платформенный файл — `reference/android-tv.md` или `reference/desktop-flutter.md`.
3. Для любой правки экрана или компонента пройди `reference/review-checklist.md`.
4. Меняй только запрошенный участок. Не мигрируй фреймворк ради локальной задачи.
5. После правки запусти профильные проверки и, если доступно устройство/эмулятор, проверь скриншоты. Отделяй «код собирается» от «визуально проверено».

## Незыблемые правила

- **Один акцент.** По умолчанию индиго `#5B4FE8`; пользователь выбирает пресет в настройках. Синий (`#4DA3FF`), зелёный (`#4CD08A` / `#10B981`) и красный (`#B91C1C` / `#FF4D5E`) — только семантика (архив, статус эфира/подключено, LIVE/ошибка), не второй бренд.
- **Текст на акценте и семантике — по контрасту.** Для индиго, синего, бирюзового, розового, красного и тёмно-красного бейджа `LIVE` (`#B91C1C`) это белый; для оранжевого и голубого (`#4DA3FF`) — тёмный `#1A0B04`.
- **Контраст.** Обычный текст ≥ 4.5:1, крупный (≥ 18.66 px/sp bold или ≥ 24 px/sp) ≥ 3:1 на *фактической* подложке (включая состояние фокуса `CardHover`). Непрозрачные нейтрали (`#CBD5E1`, `#94A3B8`) предпочтительнее полупрозрачного белого поверх видео.
- **Шкала, а не случайные числа.** Радиусы: `4 / 8 / 12 / 16` (+ `50` для пилюль). Шрифты: `12 / 14 / 16 / 20` (+ `26` для заголовков и часов 10-foot UI на Android TV, `48` для ввода номера канала). Отступы: `4 / 8 / 12 / 16 / 24 / 32`, плюс TV safe area `48×28 dp`.
- **Выбор и фокус — разные сигналы.** Активный канал/пункт помечается полосой (`SelectedBar`), галочкой или фоновой подсветкой; фокус пульта/клавиатуры — яркой рамкой `C.Accent2` (`2 dp`), а на акцентных кнопках (`prominent`) — белой внешней обводкой с зазором `3 dp`.
- **Состояния обязательны.** Загрузка с источником и номером попытки, ошибка с причиной и фокусируемым «Повторить», пауза/перемотка архива с HUD-индикацией, пустой список с действием.
- **Векторные иконки вместо псевдографики.** Не используй Unicode-символы (`◷`, `⟳`, `＋`, `★`, `✓`) в кнопках и списках — бери векторные иконки с `contentDescription`/tooltip.
- **Локализация.** Все строки и плюрали — в `strings.xml` / ARB для `ru` и `en`. Не выводи внутренние ключи (вроде `key:all`) напрямую в UI.

## Чего не делать

- Белый текст на оранжевом, голубом (`#4DA3FF`) или ярко-красном (`#FF4D5E`) фоне.
- Акцентная рамка фокуса того же цвета поверх акцентной кнопки.
- Тонкие начертания (`Light`, `Thin`) на телевизоре.
- Мелкий текст меньше `12 sp` на TV / телефоне и меньше `12 px` в десктопе.
- Анимации дольше `150 мс` для фокуса или `300 мс` для переходов.
- Эмодзи, зашитый в код текст или технический жаргон (пути к ini/lua-скриптам) в пользовательских настройках.

## Границы

Скилл описывает визуальные и UX-правила SimpleTV. Он не меняет сетевые контракты, лицензии и не разрешает добавлять зависимости ради декора. Источники принципов — `NOTICE.md`.
