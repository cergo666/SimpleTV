# Дизайн-токены SimpleTV

Источник истины в коде:

- Android: `app/src/main/java/io/mediacast/simpletv/ui/Theme.kt` (`C`).
- Desktop: `desktop/lib/ui/theme/theme.dart` (`AppColors`, `AppType`, `AppRadius`, `AppSpace`).

Если меняешь токен — меняй его в коде и в этом файле одним коммитом.

## Бренд и акцент

| Роль | Значение | Где использовать |
|---|---|---|
| Accent (по умолчанию) | `#5B4FE8` | главная кнопка, активный пункт, прогресс, фокус |
| Accent soft | `#8B7CFF` | вторая точка градиента и подсветка текста на тёмном |
| Gradient end | `#6D5DF6` | только вторая точка `accentBrush` |
| On accent | `#FFFFFF` | текст и иконки **на** индиго |
| Info | `#4DA3FF` | архив, нейтральная ссылка, не действие |
| Success | `#4CD08A` / `#10B981` | «в эфире», успешная проверка |
| Danger | `#FF4D5E` / `#EF4444` | ошибка, запись, «LIVE» |
| Live pill bg | `#B91C1C` (белый текст) | маленький бейдж LIVE, если нужен белый текст |

Правила:

- Индиго — акцент по умолчанию. Пользователь выбирает пресет в настройках; в коде нельзя хардкодить второй брендовый цвет.
- На акценте используй `onAccent` пресета: белый для индиго/синего/бирюзового/розового/красного, тёмный `#1A0B04` для оранжевого.
- На голубом и ярко-красном для мелкого текста используй тёмный `On accent` (7.64:1 и 5.92:1) или затемни фон до `#B91C1C` (белый 6.47:1).
- Красный и зелёный — семантика, а не украшение.

## Пресеты акцента

`violet` (по умолчанию), `orange`, `blue`, `teal`, `pink`, `red`. Значения заданы в `AccentPalette` на Android и `accentOptions` на десктопе; id сохраняется в настройках. При добавлении пресета проверь контраст `onAccent` на `accent` и `gradientEnd` тестом `design_tokens_test.dart`.

## Типографика

Шкала: **12 / 14 / 16 / 20**; 48 — только крупные цифры ввода номера канала.

| Токен | Размер | Назначение |
|---|---|---|
| `AppType.caption` | 12 | подписи, бейджи, метаданные |
| `AppType.body` | 14 | основной текст, списки |
| `AppType.subtitle` | 16 | заголовок карточки, кнопка |
| `AppType.title` | 20 | заголовок экрана, имя канала |
| `AppType.hero` | 48 | только цифры быстрого ввода |

Правила:

- Максимум два веса: regular и semibold/bold.
- Не опускайся ниже 12: на TV 12 sp — минимум, на десктопе 12 px.
- Длинные названия каналов: `maxLines` + `ellipsis`, не переноси в три строки.
- Числа в статистике — моноширинный вариант, если он уже есть в системе.

## Радиусы

| Токен | Значение | Назначение |
|---|---|---|
| `AppRadius.chip` | 4 | бейджи, прогресс-полоса, мелкие метки |
| `AppRadius.control` | 8 | кнопки, поля, строки списка |
| `AppRadius.panel` | 12 | панели, поповеры, группы |
| `AppRadius.card` | 16 | модальные карточки, оверлеи, плеер |

Не добавляй 6, 10, 14, 20, 24 «на глаз». Исключение — круг (`CircleShape`/`BorderRadius.circular(50)`) для пилюль и аватаров.

## Отступы

Шкала: **4 / 8 / 12 / 16 / 24 / 32**.

- Внутри группы — 4–8.
- Между группами — 12–16.
- Между секциями — 24–32.
- Паддинг карточки — 16–24.
- Горизонтальный паддинг экрана — 16 (телефон), 32 (TV/desktop wide).

2 px допустимы только для толщины линии/разделителя, не для смыслового отступа.
