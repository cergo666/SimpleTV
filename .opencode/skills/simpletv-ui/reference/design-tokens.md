# Дизайн-токены SimpleTV

Источники истины в коде:

- Android: `app/src/main/java/io/mediacast/simpletv/ui/Theme.kt` (`C`, `AccentPalette`, `AppType`, `AppRadius`, `AppSpace`, `TvSafe`).
- Desktop: `desktop/lib/ui/theme/theme.dart` (`AppColors`, `AppType`, `AppRadius`, `AppSpace`, `accentOptions`).

Если меняешь токен — обновляй его в коде и в этом файле в одном коммите.

## Пресеты акцента

`violet` (по умолчанию), `orange`, `blue`, `teal`, `pink`, `red`. Для `violet` светлый акцент `accentSoft` — `#9D91FF`, чтобы он сохранял контраст ≥ 4.5:1 на всех тёмных подложках вплоть до `CardHover` (`#253252`). Контраст проверяется тестами `AccentPaletteTest.kt` и `design_tokens_test.dart`.

## Типографика

| Токен | Android (`AppType`) | Desktop (`AppType`) | Назначение |
|---|---|---|---|
| `caption` | `12.sp` | `12` | бейджи, метаданные, шкала времени, подсказки пульта |
| `body` | `14.sp` | `14` | основной текст, описания, имена каналов в гиде |
| `subtitle` | `16.sp` | `16` | названия каналов в списке, кнопки, настройки |
| `title` | `20.sp` | `20` | заголовки панелей и секций |
| `display` | `26.sp` | — | 10-foot заголовки ТВ, InfoBar канала, часы |
| `hero` | `48.sp` | `48` | только крупные цифры ввода номера канала |

Правила:

- Два веса: `Normal`/`Medium` и `SemiBold`/`Bold`. Никаких `Light`/`Thin`.
- Минимум: `12.sp` на Android / TV и `12` px на десктопе.
- Длинные строки: `maxLines` + `TextOverflow.Ellipsis`.

## Радиусы и отступы

- **Радиусы (`AppRadius`):** `chip = 4`, `control = 8`, `panel = 12`, `card = 16` (+ `50` / `CircleShape` для круглых кнопок и пилюль).
- **Отступы (`AppSpace`):** `xs = 4`, `sm = 8`, `md = 12`, `lg = 16`, `xl = 24`, `xxl = 32`.
- **Безопасная зона TV (`TvSafe`):** `horizontal = 48.dp`, `vertical = 28.dp` для всех TV-оверлеев, `InfoBar` и OSD.
