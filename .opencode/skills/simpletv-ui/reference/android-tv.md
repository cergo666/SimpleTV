# Android и Android TV

## Общее

- Compose + Material 3. Тема — `StvTheme`, цвета — `C`.
- Новые строки — в `app/src/main/res/values/strings.xml` и `values-en/strings.xml`, плюрали — `<plurals>`.
- Все кликабельные элементы — через `FocusItem`/`clickable` с видимым фокусом.
- Минимальная цель нажатия — 48×48 dp, даже если иконка 18–24 dp.

## Android TV: 10-foot UI

Пользователь сидит в 2–3 метрах, управляет пультом.

Типографика:

- Минимум 12 sp. Для основного текста — 14–16 sp, заголовки — 20–28 sp.
- Не используй тонкие начертания (`Light`, `Thin`) — на ТВ они «исчезают».
- Не ставь важный текст на пёстрый кадр без подложки.

Фокус и пульт:

- Фокус виден всегда: рамка 2 dp акцентом или акцентная подложка, не только смена оттенка.
- Порядок D-pad должен совпадать с визуальным: сверху вниз, слева направо. Не оставляй «ловушек» фокуса.
- Начальный фокус — на главном действии экрана, а не на первом служебном элементе.
- Back закрывает оверлей/возвращает фокус, а не выходит из приложения, если открыт диалог.
- Не полагайся на hover и долгое нажатие как на единственный способ действия.

Безопасная зона:

- Держи текст и кнопки не ближе 5% от краёв (при 1080p — около 48 px). Фоновое видео может уходить под край.
- Горизонтальные паддинги: 32 dp на широком экране, 16 dp на узком.

Состояния:

- Подключение: имя источника и номер попытки.
- Ошибка: причина, список проверенных источников, кнопка «Повторить» с фокусом.
- Пустой плейлист: объяснение и кнопка загрузки, а не пустой чёрный экран.

Производительность:

- Не анимируй blur/тени на каждом кадре. Для ТВ-боксов это дорого.
- Списки — `LazyColumn`/`LazyRow` со стабильными `key`.
- Статистику и логотипы обновляй по таймеру, а не на каждый кадр.

## Android-телефон (портрет)

- Видео сверху, список каналов снизу; основные действия — в нижней трети.
- Учитывай системные вставки (navigation bars, cutout) через WindowInsets.
- Пилюли и группы — горизонтальный скролл, не сжимай подписи до нечитаемости.
- Проверяй поворот экрана и «картинку в картинке»: состояние не должно сбрасываться.

## Проверка

- `./gradlew :app:lintDebug :app:ktlintCheck :app:testDebugUnitTest`
- Вручную: экран загрузки, ошибки, пустого списка; фокус с пульта; Back из каждого оверлея; длинное название канала; английская локаль.
