# Чек-лист UI-ревью

Проверяй по порядку: каждый пункт соответствует конкретному классу дефектов.

## 1. Иерархия и плотность

- [ ] Главное действие и текущий статус читаются первыми.
- [ ] Активное состояние (`SelectedBar` / `Check`) не путается с фокусом пульта.
- [ ] Описание передачи и технические метаданные не дублируются на одном экране.
- [ ] При предпросмотре видео в списке каналов остаётся достаточно высоты для телепрограммы (≥ 4 строк).

## 2. Контраст и цвет

- [ ] Обычный текст ≥ 4.5:1, крупный ≥ 3:1 на реальной подложке, включая `CardHover` при фокусе.
- [ ] Белый текст не стоит на оранжевом, голубом (`#4DA3FF`) или ярко-красном (`#FF4D5E`). Для `LIVE` используется `#B91C1C`.
- [ ] Акцентная кнопка в фокусе имеет внешнюю контрастную обводку (белую с зазором), а не рамку цвета самой кнопки.
- [ ] Карточки и панели на тёмных подложках не пропускают пёстрое видео до нечитаемости.

## 3. Шкала и иконография

- [ ] Радиусы: `4 / 8 / 12 / 16` (круг/пилюля — `50`).
- [ ] Шрифты: `12 / 14 / 16 / 20` (`26` для TV-заголовков/часов, `48` для номера канала). Нет текста меньше `12 sp/px` и начертаний `Light`/`Thin`.
- [ ] Отступы: `4 / 8 / 12 / 16 / 24 / 32` + `TvSafe` (`48×28 dp`).
- [ ] Вместо Unicode-глифов (`◷`, `⟳`, `＋`, `★`, `✓`) в кнопках и списках используются векторные иконки.

## 4. Состояния и обратная связь

- [ ] Загрузка, ошибка (с фокусом на «Повторить»), пустое состояние, пауза (HUD) и перемотка архива явно отображаются.
- [ ] Клик по будущей или недоступной в архиве передаче даёт понятное сообщение, а не молчит.
- [ ] Долгая операция не блокирует интерфейс и не сбрасывает фокус/скролл.

## 5. Управление (D-pad, клавиатура, тач)

- [ ] Цели нажатия ≥ `48 dp` (Android) / ≥ `32 px` (desktop).
- [ ] Фокус не вырывается из групп, поиска и настроек при выборе или переключении тумблеров.
- [ ] Ошибка воспроизведения и `Welcome` позволяют перемещаться между кнопками и нажимать `OK`.
- [ ] `Esc` / `Back` закрывают оверлей и возвращают фокус; поля ввода имеют видимый фокус.
- [ ] На TV показаны краткие подсказки кнопок пульта (`RemoteHintBar`).

## 6. Текст и локализация

- [ ] Нет сырых ключей (`key:all`) или зашитых в код пользовательских строк.
- [ ] `ru` и `en` обновлены вместе; плюрали — через ресурсы/ICU.
- [ ] В настройках нет лишнего dev-жаргона (путей к lua/ini).

## 7. Адаптивность и безопасные зоны

- [ ] На TV учтена безопасная зона `48×28 dp`.
- [ ] На телефоне учтены `WindowInsets.safeDrawing` и экранная клавиатура (`.imePadding()` / скролл в диалогах).
- [ ] В `TvGuide` шкала времени выровнена по сетке, видна дата, длинные названия каналов не обрезаются до нечитаемости.

## Команды

```bash
./gradlew :core:test :app:testDebugUnitTest :app:lintDebug :app:assembleDebug ktlintCheck
cd desktop && dart format --output=none --set-exit-if-changed lib test tool && flutter analyze && flutter test --exclude-tags native-playback
```

Визуальную проверку на эмуляторе/окне всегда указывай отдельно от компиляции и unit-тестов.
