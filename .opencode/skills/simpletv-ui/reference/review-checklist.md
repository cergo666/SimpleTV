# Чек-лист UI-ревью

Проверяй по порядку. Это не оценка вкуса, а поиск конкретных дефектов.

## 1. Иерархия

- [ ] Главное действие/сообщение читается первым.
- [ ] Второстепенное не спорит с главным по размеру и цвету.
- [ ] Группы разделены отступами, а не только рамками.
- [ ] Заголовок не повторяется в подзаголовке без новой информации.
- [ ] На экране нет двух одинаковых по весу кнопок с разными действиями.

## 2. Контраст и цвет

- [ ] Обычный текст ≥ 4.5:1, крупный ≥ 3:1.
- [ ] Белый текст не стоит на оранжевом/голубом/ярко-красном.
- [ ] Приглушённый текст не темнее `#7E8CA3` на десктопе.
- [ ] Один акцент; красный/зелёный/синий — только семантика.
- [ ] Цвет не единственный носитель смысла.
- [ ] Фокус видим и контрастен.

## 3. Шкала

- [ ] Радиусы только 4/8/12/16 (круг — исключение).
- [ ] Шрифты только 12/14/16/20 (48 — цифры ввода).
- [ ] Нет текста меньше 12 px/sp.
- [ ] Отступы из 4/8/12/16/24/32; 2 px — только линии.
- [ ] Весов шрифта не больше двух.

## 4. Состояния

- [ ] Загрузка объясняет, что происходит.
- [ ] Ошибка называет причину и способ восстановления.
- [ ] Пустой список предлагает действие.
- [ ] Успех/активное состояние заметно, но не кричит.
- [ ] Долгая операция не блокирует интерфейс и не запускается дважды.

## 5. Управление

- [ ] Цели нажатия ≥ 48 dp (Android) / ≥ 32 px (desktop).
- [ ] Порядок фокуса совпадает с визуальным.
- [ ] Esc/Back закрывают оверлей и возвращают фокус.
- [ ] Иконки без подписи имеют tooltip/accessibility label.
- [ ] Hover не является единственным сигналом интерактивности.

## 6. Текст и локализация

- [ ] Нет зашитых строк в коде.
- [ ] ru и en обновлены вместе.
- [ ] Плюрали через ресурсы, а не склейка.
- [ ] Длинный перевод не обрезает главное действие.
- [ ] Даты/время — по локали.

## 7. Адаптивность

- [ ] Проверены узкий и широкий режимы.
- [ ] Длинные названия не ломают строку.
- [ ] Списки скроллятся, последний элемент достижим.
- [ ] На TV учтена безопасная зона 5%.
- [ ] На десктопе окно не меньше 960×600.

## 8. Движение

- [ ] Анимация имеет цель (обратная связь, смена состояния, непрерывность).
- [ ] Частые действия — без анимации или < 150 мс.
- [ ] Вход/выход < 300 мс, ease-out.
- [ ] Нет анимации данных, которые пользователь читает.
- [ ] Учитывается reduced motion, где платформа это поддерживает.

## Команды

```bash
./gradlew :app:lintDebug :app:ktlintCheck :app:testDebugUnitTest
cd desktop && flutter analyze && flutter test
```

Визуальную проверку указывай отдельно. Если экран не открывался, чек-лист по нему не закрыт.
